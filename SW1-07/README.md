# SW1-07 Classes Objects and References

Student task: Complete `MatchCounter.java`.

* Store a private integer field named `count`.
* The no-argument constructor starts count at 0.
* `increment()` increases count by 1.
* `add(amount)` increases count by amount.
* `getCount()` returns count.
* The supplied test creates two counters. Make sure each object keeps its own count.

Run:

    javac *.java
    java ProctorTest
