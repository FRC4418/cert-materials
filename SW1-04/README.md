# SW1-04 Methods Parameters and Scope

Student task: Complete `DriveMath.java`.

* `clamp(value, minimum, maximum)` returns the nearest allowed value when `value` is outside the range; otherwise it returns value.
* `average(first, second)` returns the average as a `double`.
* Overload `average` with a version that accepts three `double` values.
* `report(speed)` returns exactly `Speed: ` followed by the clamped speed from 0.0 through 1.0.
* In code review, explain which identifiers in one method are parameters and which are local variables.
