# SW2-08 — Driver Station, Build, Deploy, and Disable

## Prerequisites
- SW2-00 through SW2-07; mentor permission for an approved training robot.

## Goal
Show safe basic setup and deployment for a student who will help with programming, not electrical commissioning.

## Student files
- This task uses a fresh WPILib-generated project; no prewritten Java solution is provided.

**Student may edit** the starter files and the generated WPILib project, but must NOT edit any ProctorTest.java or PROCTOR_RUBRIC.md. Reuse the completed files from previous SW2 assessments when stated; do not copy a proctor's solution. 

## Procedure
1. Under mentor direction, use USB/Ethernet or team-approved radio link. Identify the robot code status and Driver Station communications indicators. Confirm the target team number and test robot.
2. Build and deploy the SW2 training project with zero motor demands at startup. Show successful deployment and find the startup print in RioLog.
3. Proctor calls for Teleop Enable followed by Disable; student demonstrates they can identify and use the correct controls. Student does not independently run motors without proctor permission.
4. Given one simple symptom (no robot communication, no code, wrong project, or compile failure), the student describes a plausible first diagnostic check and does not blindly re-image/change radio settings.

## Preparation
WPILib: Driver Station; Building and Deploying Robot Code; Viewing Console Output.

Do not enable or deploy live motor code until the proctor verifies safety.
