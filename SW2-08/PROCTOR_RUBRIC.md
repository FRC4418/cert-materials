## Required behavior (all must pass)
- [ ] Student verifies correct target and successful deployment.
- [ ] RioLog includes expected startup output.
- [ ] Student promptly disables robot when directed and states the safety procedure.
- [ ] Student correctly identifies at least one common Driver Station error category; no configuration of competition networking is required.

## Reproducible evidence
1. Under mentor direction, use USB/Ethernet or team-approved radio link. Identify the robot code status and Driver Station communications indicators. Confirm the target team number and test robot.
2. Build and deploy the SW2 training project with zero motor demands at startup. Show successful deployment and find the startup print in RioLog.
3. Proctor calls for Teleop Enable followed by Disable; student demonstrates they can identify and use the correct controls. Student does not independently run motors without proctor permission.
4. Given one simple symptom (no robot communication, no code, wrong project, or compile failure), the student describes a plausible first diagnostic check and does not blindly re-image/change radio settings.

## Safety / test policy
- This is a beginner FRC programming assessment. No simulation or advanced control is required.
- If a physical motor is involved, an authorized proctor controls the enable/disable process, checks current limits and secures the test bench.
- No production robot deployment, unapproved wiring, or bypass of safety interlocks.
- Any `ProctorTest.java` file is protected and must remain unchanged.
