# SW1-01 Variables Types and Calculations

Student task: Complete `PartsCalculator.java` for a practice parts order.

* `totalCost(quantity, price)` returns quantity times price.
* `averageCost(total, quantity)` returns total divided by quantity as a `double`.
* `roundedBins(quantity, binSize)` returns the number of full or partial bins needed. For example, 13 parts in bins of 5 needs 3 bins.
* In `main`, declare a `final double TAX_RATE = 0.0825`, calculate the tax on a $120.00 order, and print exactly `Tax: 9.9`.

Run:

    javac *.java
    java ProctorTest
