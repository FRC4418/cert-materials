# SW1-03 Loops and Repeated Work

Student task: Complete `PitStopCounter.java`.

* `countInspections(items)` counts from 1 through `items` with a `for` loop and returns the count. For 4, return 4.
* `sumHours(hours)` uses a loop to add every value in the supplied `int[]`.
* `countUntilReady(startingParts, targetParts)` uses a `while` loop to count how many one-part deliveries are needed. If starting parts already meets the target, return 0.
* `main` prints `Inspections: 3` when it calls `countInspections(3)`.

Run:

    javac *.java
    java ProctorTest
