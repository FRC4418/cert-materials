# SW1-06 Arrays and Iteration

Student task: Complete `ScoreStatistics.java`.

* `sum(scores)` returns the sum of every score in the array.
* `average(scores)` returns the average as a `double`.
* `highest(scores)` returns the greatest score.
* `countPassing(scores)` counts scores that are 70 or higher.
* Use a `for-each` loop in at least one method and an index-based `for` loop in at least one method.

Run:

    javac *.java
    java ProctorTest
