# SW1-11 Lists Generics and Imports

Student task: Complete `InventoryList.java`.

* Import `java.util.ArrayList` and `java.util.List`.
* Store the parts in a private `List<String>` initialized to a new `ArrayList<String>`.
* `add(part)` adds one part.
* `contains(part)` returns whether the exact part is in the list.
* `remove(part)` removes the part and returns whether removal happened.
* `size()` returns the number of parts.

Run:

    javac *.java
    java ProctorTest
